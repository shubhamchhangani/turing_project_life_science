# Conditional receptor ensemble

Original synthetic finite equilibrium model of a cooperative receptor sheet.
The biological interpretation is a coarse-grained two-conformation lattice, not
an atomistic receptor or an experimentally fitted biological system. Six sites
are clamped to specified conformations and the full eight-reporter conditional
distribution is requested. All units, boundary conditions and normalizers are
explicit in instruction.md.

## Data and independent expectations

`tests/provenance/generate.py` specifies the original seeded graph and couplings.
The input has 1024 sites, positive spatially varying pair couplings and no fields.
It contains no solution, fitted outputs or hidden physical constants.

`tests/provenance/independent_source.py` computes expected values directly from
the graph, without importing the reference solver or consuming its output. The
source uses the high-temperature even-subgraph polynomial, common-root paths,
outgoing-edge weighted Kac-Ward matrices and explicit character sums. The
reference uses paired paths, incoming-edge weights and a Walsh transform.
These are separate implementations of the same exact mathematical identity;
they are not independent physical theories. `check_small.py` independently sums
all 512 spin assignments on six small triangular grids to check the reference.
The full-size expectation file is generated by the separate source, not copied
from a reference run. Its `source` field records this provenance.

For an even set A of sites, toggle edges along any path set whose odd-degree
vertices are A. Multiplying the toggled edge weights by their reciprocals in the
even-subgraph polynomial, with a compensating product of original weights,
gives the spin-product moment. Positive couplings make these moment polynomials
positive, resolving the square-root sign of the determinant. Odd moments vanish
by global spin inversion. Character inversion then gives joint probabilities;
conditioning yields the requested reporter ensemble.

Method reference: Aizenman and Warzel, *Kac-Ward formula and its extension to
order-disorder correlators through a graph zeta function*,
https://arxiv.org/abs/1709.06052 . This source supports the mathematical method;
it is not the source of the task instance or numeric expectations.

## Verification

The verifier checks both logarithms and every one of the 256 probabilities,
plus normalization. The 5e-8 absolute probability allowance and 2e-6 logarithm
allowance accommodate floating-point factorization, cancellation and CSV
rounding; they do not require bitwise agreement. The small exhaustive checks
and full-instance cross-implementation agreement are recorded by the author
before the frozen model trial. Sampling error or independence approximations
are not substitutes for meeting the explicit finite-model accuracy contract.

The verifier runs offline and reads only bounded regular output files; it never
executes agent code. Strict numeric grammar rejects whitespace, non-ASCII
digits, underscores and nonfinite values. Contract validation precedes every
scientific check. All numeric expectations remain private to the verifier.

## Completed author checks and release status

The input-only reference completed with one CPU and 2 GiB RAM in an offline
container. Its outputs passed all four tests in a separate offline verifier.
Six exhaustive 3-by-3 checks had maximum probability discrepancy 1.25e-16.
The independent source was additionally checked against a four-spin exhaustive
enumeration. Full-instance source/reference discrepancy was below 6.6e-17 for
every conditional probability; both logarithms agreed at reported precision.
Host timings were 121.2 seconds for the reference and 96.8 seconds for the
independent source. These measurements support tolerances far above observed
numeric differences, while keeping scientific differences detectable.

Adversarial regressions accepted three valid format variants and rejected 280
invalid or scientifically incorrect outputs. These included perturbing each
joint probability while preserving normalization, and replacing the law by a
product having the correct individual marginals. All package static checks
passed before freezing the task for model trials.
